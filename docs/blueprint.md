# **App Name**: PriceWise

## Core Features:

- Price Comparison Table: Display product prices across various stores in a clean, tabular format.
- Lowest Price Finder: Allow users to input a product name and view the store offering the lowest price.
- Product Suggestion Engine: Suggest related products based on the user's search history. This feature will use an LLM tool to suggest products that a user might be interested in based on the their search history

## Style Guidelines:

- Primary color: Teal (#008080) to convey trustworthiness and savings.
- Secondary color: Light gray (#F0F0F0) for a clean background.
- Accent: Gold (#FFD700) to highlight the lowest prices and special offers.
- Use a grid layout for product display and a clear, simple form for adding/updating prices.
- Use icons to represent different stores or product categories.
- Subtle transition animations when prices are updated or new products are loaded.
